## Design Pattern Analysis

### Layout Patterns
1. **Hero pattern:** Full-width bg image + H1 + subtitle + single CTA button (used on 8/11 pages)
2. **Two-column alternating:** Image left + text right (or reversed) — main content pattern across all pages
3. **Feature card grid:** H4 title + image + short description + CTA — used for clinical applications and team
4. **Full-width band:** Large heading + body + optional CTA over full-bleed bg image (used for callouts/stats)
5. **Numbered/bulleted list block:** H2 + body + bullet list (used for benefits, features, research)

### Color/Visual Patterns
- **Primary palette:** Deep navy/dark teal background with white text
- **Accent:** Teal/cyan blue (`#1a9fbf` approximate)
- **CTA buttons:** Dark navy with white text (filled) or outline style
- **Section backgrounds alternate:** `w-png.webp` (lighter) ↔ `ov-png.webp` (darker) creating visual rhythm
- **Hero sections:** Deep blue particle/cell bokeh aesthetic

### CTA Placement Patterns
- "Contact us" — hero CTA on interior pages
- "More Info" / "Read More" — mid-page feature sections
- "Get In Touch" — persistent in header
- Contact form — appears on Home (bottom) and Contact Us page

### Image Usage Style
- Product photography: Vial renders on white/transparent backgrounds
- Condition cards: Illustrated/stylized medical icons (PNG format)
- Scientific diagrams: Abstract molecular/cellular visualizations
- Hero backgrounds: Full-bleed photography with overlay (blue-tinted)
- Condition detail sections: Full-bleed photographic backgrounds (hospitals, biology imagery)

### Video Usage Patterns

|---|---|---|---|---|
| `hero-slider.mov` | Home | Hero | 8MB | MOV (looping bg) |
